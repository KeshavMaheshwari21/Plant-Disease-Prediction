# Plant Disease Classifier 🌱

This is a simple **Plant Disease Classifier** web app built using **TensorFlow**, **Streamlit**, and **Pillow** (PIL) for image processing. The model predicts the disease category of a plant based on an uploaded image.

## Features

- Upload an image of a plant leaf in **.jpg, .jpeg,** or **.png** format.
- The model predicts the class of the plant disease.
- Displays the predicted disease class name.

## Requirements

To run this project locally, you need the following dependencies:

```bash
pip install numpy
pip install tensorflow
pip install pillow
pip install streamlit
```
